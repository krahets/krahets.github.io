# krahets.com

Personal website of [Yudong Jin](https://krahets.com) (@krahets).

Built with plain HTML + CSS + vanilla JS, no framework, no build step. Originally designed with [Claude Code](https://claude.ai/claude-code) using the [impeccable](https://github.com/pbakaus/impeccable) skill pack (typography, color, layout, polish), and maintained with Codex.

> [!TIP]
> Feel free to use this as a template. A link back to [krahets.com](https://krahets.com) would be appreciated.

## Usage

Ask Codex or Claude Code to:

1. Update `CLAUDE.md` with your personal info (name, email, GitHub, social links, research interests, etc.).
2. Replace assets in `assets/` (profile photos, publication videos, thumbnails, etc.).
3. Edit your content in `index.html`.

For AI-assisted edits, keep `CLAUDE.md` as the authoritative project instruction file. To redesign the page with Claude Code, install the [impeccable](https://github.com/pbakaus/impeccable) skill pack (see `skills-lock.json`) for design skills like `/typeset` and `/polish`.
