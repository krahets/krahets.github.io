# krahets.com

Personal website of [Yudong Jin](https://krahets.com).

Built with plain HTML + CSS, no framework, no build step. Designed with [Claude Code](https://claude.ai/claude-code) using the [impeccable](https://github.com/pbakaus/impeccable) skill pack (typography, color, layout, polish).

## Usage

Feel free to use this as a template. If you do, a link back to [krahets.com](https://krahets.com) is appreciated.
